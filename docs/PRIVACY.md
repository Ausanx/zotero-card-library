# 隐私与数据边界

插件通过 Zotero API 读取个人库条目、作者、出版物、年份、DOI、摘要、标签、合集、普通笔记和 PDF 附件路径。只在本地解析 PDF 和生成图片，不直接操作 Zotero 数据库文件。

运行时没有远程请求代码、遥测、AI 接口或账号系统。Zotero 本身的同步、插件更新检查和原生阅读器功能仍由 Zotero 控制。插件更新清单位于 GitHub Releases；Zotero 请求此清单时不会附带文献内容。

插件状态位于 Zotero profile（不是文献数据目录）中的 `zotero-card-library/state.json`，包含收藏、阅读状态、颜色规则、简记字段键、附件选择、封面坐标、搜索及窗口状态。封面缓存位于 `covers/`，是正文区域或首页渲染图和候选坐标，可能包含论文内容。

JSON 备份不包含 PDF 原文、笔记正文或完整文献元数据；它包含本地条目 ID、标签规则文字、搜索词和封面缓存键，缓存键可能含附件的本地路径。因此备份也应视为私人文件。备份不包含封面图缓存；恢复后可由原 PDF 重建。

仅“多选 → 选择目标合集 → 加入合集”改变 Zotero 合集关系。打开 PDF 使用原生 Reader，Zotero 会记录其阅读时间与位置。其他操作不写 Zotero 标签、字段、笔记或注释。手动裁剪只保存封面坐标。

状态损坏时保留 `.corrupt-时间戳` 文件并使用默认状态；未来版本的状态不会被静默覆盖。卸载保留状态和缓存，重装同一库后可继续使用。彻底删除时先退出 Zotero，再删除上述插件目录。
