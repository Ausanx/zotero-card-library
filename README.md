# Zotero Card Library

为 Zotero 9.0.6 提供独立的卡片式文献库。界面借鉴参考图中的卡片布局、色彩组织和信息层级：整块色卡、圆角瀑布流、图片与按钮并排、紧凑侧栏，以及独立文献详情窗口。Zotero 仍负责文献管理和原生 PDF 阅读；本插件的功能与参考产品不同。

## 安装

1. 构建或取得 `zotero-card-library.xpi`。
2. 在 Zotero 的“工具 → 插件”中点击齿轮，选择“从文件安装插件”，选中 XPI。
3. 回到 Zotero 主窗口，在顶部菜单选择“工具 → 卡片式文献库”打开窗口。

安装或更新后请重启 Zotero，再从主窗口菜单打开插件。

支持 Zotero **9.0.6 至 9.x**。当前为本地试用版本 0.1.3，尚未发布到插件市场；暂不提供在线自动更新。

## 使用

- 卡片显示完整标题、紧凑作者栏、期刊和年份；单击或按 Enter / Space 打开独立详情窗口。再次点击卡片复用该窗口并切换内容；可单独调整窗口大小，Escape 关闭。关闭卡片库时一并关闭详情。
- 正文 Figure 优先作为封面。详情中点击“加载候选图”后可选其他候选图、切换 PDF 来源，或手动框选任意页面；没有候选时使用首页。打开详情先显示元数据，不自动生成候选预览。
- 搜索标题、作者、期刊、标签、摘要、普通笔记和映射的简记；可按合集、标签筛选及按最近添加、最近打开、年份、标题、作者排序。
- 收藏、未读 / 在读 / 已读、卡片颜色和浅色 / 深色主题只存于插件状态。打开 PDF 将未读改为在读；已读需要手动设置。
- 默认未读为淡蓝紫色、在读为浅蓝色、已读为浅青绿色，本地 PDF 不可用为灰色。单卡自定颜色和合集 / 标签颜色规则优先；这些颜色不代表期刊等级。
- 简记默认自动识别 Ethereal Style 的 `extra` 中 `remark:` 内容，以及旧版带 `remark` 标签的子笔记；用于搜索并在详情中完整显示。在“外观与本地设置”填写其他字段键（如 `shortTitle`）可覆盖自动识别，留空恢复自动识别。
- 多选卡片后选择目标合集，再点击“加入合集”。这是插件唯一主动改变 Zotero 文献组织关系的操作。

## 备份与隐私

状态在 Zotero profile 的 `zotero-card-library/state.json`；封面缓存在同目录的 `covers/`。设置中可导出 / 导入 JSON 备份。导入会替换插件状态，校验失败保留原状态。备份适用于同一文献库：条目和附件采用本地 ID，不能作为跨库迁移工具。

插件不调用大模型、远程 AI、Zotero Web API，不上传文献、PDF、封面或笔记，不提供遥测。封面计算使用 Zotero 自带 PDF.js。详见 [隐私与数据说明](docs/PRIVACY.md)。

卸载后文献和附件保持原状；本地状态和缓存保留以便重装。需要彻底清理时，关闭 Zotero 后删除 profile 内的 `zotero-card-library` 文件夹。

## 已知限制与排错

- 规则识别适合有文本图注的 PDF。扫描版、复杂矢量图、跨页 Figure、多栏混排可能识别不完整；用候选切换或手动框选修正，不提供 OCR。
- 缺失或尚未下载的 PDF 仍显示元数据。先在 Zotero 中下载附件或重新定位链接文件，再刷新。
- 第一版读取个人文献库，不提供群组库入口；界面文案以简体中文为主。
- 收藏是本地标记，当前没有独立收藏筛选页。
- 不能加载卡片窗口时，查看 Zotero“帮助 → 调试输出”及错误控制台。反馈时避免附上私人文献数据。

## 开发

需要 Node.js 22.8+。运行 `npm ci`，然后：

```sh
npm test
npm run lint:check
npm run build
npm run verify:package
```

产物在 `.scaffold/build/`。`npm run test:zotero` 在全新的测试 profile 中创建 238 条合成文献，使用本地 PDF 离线验收，不访问用户的实际文献库。设置 `ZOTERO_BIN` 指定 Zotero 程序路径。详见 [开发说明](docs/DEVELOPMENT.md) 和 [发布说明](docs/RELEASE.md)。
